# 2：二進位亮點

計算非負整數的二進位表示中，有多少個位元為 `1`。例如 13 的二進位表示為 `1101`，共有三個 `1`。

## 輸入格式
一個整數 `n`，範圍為 0 至 1,000,000。

## 輸出格式
第一行輸出值為 `1` 的位元數量。輸入 0 時輸出 0。

## 實作要求
必須定義 int count_bits(unsigned int n)，main 必須實際呼叫並輸出回傳值。count_bits 必須使用 & 以及右移 >>（包含 >>=）計算值為 1 的位元數，不得用字串轉換、以除法和取餘數取代位元運算，或使用 __builtin_popcount 等直接提供位元計數結果的內建函式。要求的運算必須參與結果計算，不接受無作用的裝飾程式碼。

```c
int count_bits(unsigned int n);
```

請勿輸出提示文字。
