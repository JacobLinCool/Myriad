# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Students enter a self-declared student ID and freely participate in published programming exams. Designated teachers author, validate and rejudge exams locally, including through agents.
## Product Purpose
A distributed C programming exam platform with browser execution and teacher-local verification. The hosted system never executes student or reference programs.
## Capabilities and Constraints
Multiple public exams, isolated drafts, durable resumable submissions, local immutable bundles, teacher-owned publication and private teacher verification reports. Student identity is not authenticated; public student APIs expose only in-exam summaries. Student use ends at the deadline; no final-grade publication or post-exam student portal exists. Browser telemetry is diagnostic and device associations are investigation leads.
## Brand Commitments
Traditional Chinese interface; Codex screenshot is the visual authority. Dark neutral app shell with narrow navigation rail, problem list, central statement/editor split and right judge panel.
