# KaTeX 0.19.0 font notices

`FONT-NOTICES.txt` preserves the copyright and license-description strings
(OpenType name IDs 0 and 13) from all 20 TTF files in the installed
`katex@0.19.0/dist/fonts/` directory. These strings identify SIL Open Font
License 1.1 and the Reserved Font Names. The package's root MIT license
does not replace these font notices.

The upstream `v0.19.0` release is commit
`6ea2dc97188f0cc282e05a9690418ae7fe5457ba`. Its
[Main-Regular font](https://raw.githubusercontent.com/KaTeX/KaTeX/6ea2dc97188f0cc282e05a9690418ae7fe5457ba/fonts/KaTeX_Main-Regular.ttf)
matches the installed file, SHA-256
`d0332f52868370fd83ae7fa46470f90c8f2eab2fcf12bc4f88080b340c95a830`.

`OFL.txt` is the unchanged license body from the
[official SIL Open Font License text](https://openfontlicense.org/documents/OFL.txt),
retrieved on 2026-10-23. The official file's illustrative copyright header
was omitted; the actual copyright and Reserved Font Names are preserved in
`FONT-NOTICES.txt`. The license body has SHA-256
`ebc109078c06f79af74cf2b27454c262830d12a65749f0e2bf25d1ac1db7a02a`.

The build copies these files without network access and requires review of
the font notices when the KaTeX package version changes.
